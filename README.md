# Fashion Village — Heritage Weaves & Royal Silks

Fashion Village is an editorial, responsive luxury e-commerce web platform for authentic South Asian handloom heritage weaves, pure Kanchipuram bridal drapes, Banarasi brocades, daily luxe silk wear, and bespoke concierge styling services.

## Key Features
- **Editorial Sovereign Collections**: Full-width high-definition responsive visual showcases across Kanchipuram, Banarasi, and everyday collections.
- **Pure Silk & Tested Zari Guarantee**: Silk Mark Organization certified mulberry silk with 100% lab-tested metallic silver-gilt zari assay.
- **Interactive Trousseau Concierge**: Interactive booking modal for private 4K video styling trials and direct WhatsApp stylist consultations.
- **Sovereign Vaults Mobile Navigation**: High-fashion typography (Cormorant Garamond & Playfair Display), custom categories, badges, and responsive action tiles.
- **Figma-Accurate Royal Cream Footer**: Responsive 4-column layout with certified trust badges, newsletter subscription, and international luxury shipping guarantees.

## Tech Stack
- HTML5 Semantic Architecture
- Vanilla CSS3 (Custom Luxury Design System with variables, responsive media queries, and fluid typography)
- Vanilla JavaScript (Modal management, currency conversion, live search autocomplete, slide-over drawers)

## Running Locally
Run with any static HTTP server:
```bash
python -m http.server 5500
```
Open [http://localhost:5500](http://localhost:5500) in your browser.
